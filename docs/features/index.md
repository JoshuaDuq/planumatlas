# Features

Every feature of the viewer has its own page. Each page gives the same things in the same order: what the feature does, the data it uses, how that data was processed (steps and parameters), how the viewer draws it, the checks it passes with measured values, its limits, and the commands that reproduce it.

Counts are for the published CDMD anatomy.
